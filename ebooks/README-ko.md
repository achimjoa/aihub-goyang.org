# 글로벌 AI 허브 전자책 도서관 v1.0

## 설치

1. ZIP을 풀어 나온 `ebooks` 폴더를 기존 웹사이트 저장소의 공개 루트에 그대로 올립니다.
2. 홈페이지와 같은 배포 루트에서 `/ebooks/`에 접속합니다. 프로젝트 경로 아래에 배포되는 환경에서는 해당 프로젝트 경로 뒤에 `/ebooks/`를 붙입니다.
3. 목록 및 뷰어의 ‘전체 보고서’ 버튼은 상위 디렉터리의 기존 `library.html`로 연결됩니다. 기존 회원 페이지와 인증 설정을 그대로 사용하는 구성입니다. 이 폴더에는 공개 소개판 페이지만 들어 있습니다.

목록에 직접 연결할 때는 `/ebooks/`를 사용합니다. 개별 전자책 주소는 `/ebooks/?book=issue-01`, `/ebooks/?book=issue-02`입니다.

## 수록 내용

- 제1호 28쪽 · 앞표지, 첨부 Intro PDF 26쪽, 뒤표지. 원본의 대외비 표기를 포함하여 첨부 페이지를 보존했습니다.
- 제2호 32쪽 · 앞표지, 첨부 Intro PDF 30쪽, 뒤표지. 인쇄용 펼침 표지의 좌우 면을 분리해 사용했습니다.
- PDF 페이지에 있는 표와 레이아웃을 그대로 보여 주는 이미지 기반 뷰어입니다. 원본 PDF가 이미지 기반이므로 페이지 본문의 텍스트 검색이나 선택 기능은 제공하지 않습니다.

## 후속 호수 추가

1. `assets/issue-03/`에 앞표지를 포함한 페이지 이미지를 `01.webp`, `02.webp` 순으로 저장합니다. 기존 호수와 같은 A4 세로 비율을 사용합니다.
2. `catalog.js`의 배열 끝에 다음 형식으로 항목을 추가합니다. `pages`에는 앞뒤 표지를 포함한 총 페이지 수를 넣습니다. `contents`의 각 항목은 `[목차 수준, 제목, 전자책 페이지 번호]` 순입니다.

```js
{
  "id": "issue-03",
  "number": 3,
  "title": "제3호 제목",
  "date": "2026.11.30",
  "pages": 24,
  "contents": [[1, "앞표지", 1], [1, "머리말", 3], [1, "뒤표지", 24]]
}
```

3. 목록에서 새 책이 열리는지, 첫 페이지와 마지막 페이지가 표시되는지 확인합니다.

뷰어 조작은 페이지 버튼, 키보드 좌우 키, 모바일 좌우 밀기, 목차 선택, 페이지 번호 입력을 지원합니다. 전체화면 API를 사용할 수 없는 브라우저에서는 뷰어가 화면 안을 채웁니다.
